# Security Policy

Agent Kronig is alpha research software. Its repository agent can edit files and run reviewed commands under the current operating-system user, so defects can affect local research data.

## Report privately

Do not open a public issue for credentials, vulnerabilities, private repository data, proprietary Sentaurus material, licensed logs, signing keys, or exploitable approval-boundary failures.

Send a private report to the NovAtom Labs maintainers through the organization's established security contact. If no private contact is available to you, contact a project maintainer directly and ask for a private reporting channel before sharing technical details.

Include only the minimum information required to reproduce the problem:

- affected Agent Kronig version and package
- operating system and architecture
- impact and affected security boundary
- exact reproduction steps using non-sensitive sample data
- relevant sanitized logs
- suggested mitigation, if known

Remove API keys, tokens, usernames, private paths, customer data, proprietary simulator inputs, and licensed output before sending a report. Rotate any credential that may have been exposed.

## Supported versions

Only the latest published alpha is evaluated for security fixes. Alpha packages are currently unsigned and updates are manual. Check the official GitHub Releases page and verify downloads against the attached checksum manifest.

## Security boundaries

- The selected repository is the default file and command boundary.
- Access outside it, network activity, package installation, destructive commands, Git mutation, and remote mutation require explicit approval.
- Delegated agents cannot widen the primary agent's authority.
- Simulator input is generated by deterministic adapters, not executed from arbitrary model text.
- Credentials and proprietary simulator documentation must not be committed or packaged.
- Electron owns an authenticated loopback backend that is not a supported public web service.

These controls reduce risk but do not provide VM isolation. Run the alpha only on non-production research workstations with backups and least-privilege credentials.
