# Agent Kronig 0.1.0 Alpha 9

Agent Kronig is now distributed as a self-contained native TCAD research workspace for Linux, Windows, Intel Mac, and Apple Silicon. This prerelease is intended for internal pilot evaluation and reproducible workflow testing.

Alpha 1 through Alpha 8 were not published. Their gated builds exposed release-only assumptions in knowledge-source paths, simulator interpreter selection, runner diagnostics, platform-specific math packages, cross-platform imports, artifact scanning, Windows text decoding, Windows command parsing, frozen math-runtime collection, unsigned Electron packaging, Linux package ownership metadata, and test behavior across operating systems.

Alpha 9 removes developer-machine paths, preserves virtual-environment interpreter identity, forces UTF-8 at native boundaries, exports the build interpreter explicitly, locates the pinned Windows MKL runtime, bundles its DLL set with the frozen DEVSIM sidecar, and executes every frozen simulator sidecar before packaging. It also parses Windows interpreter paths consistently for policy and activity metadata, runs scripted repository validation safely from PowerShell, uses platform-valid paths and newline handling in the test suite, avoids reading a byte-range-locked file on Windows, provides the Linux package homepage and maintainer metadata required by electron-builder, scans frozen executables as binaries and actual ZIP packages as archives, and removes only empty signing inputs before electron-builder starts.

The release also imports the POSIX-only Sentaurus resource limiter only on its supported execution host, pins the public DEVSIM knowledge source to the reviewed manifest commit, and exposes bounded test and scanner failures through release checks.

## Unsigned alpha

The Alpha 9 packages are not code signed or notarized. Windows SmartScreen, macOS Gatekeeper, and some Linux security tools may show warnings. Install only files attached to the official `v0.1.0-alpha.9` GitHub release and verify them against `SHA256SUMS.txt`.

Do not redistribute these packages as production software. Signing and notarization are required before broader deployment.

## Manual updates

This release does not publish an automatic update channel. To upgrade, finish or stop active agent and simulator runs, close Agent Kronig, back up its application-data directory, and install a newer release package. Selected repositories remain ordinary local folders and are not removed by uninstalling the application.

## Current capabilities

- Native three-pane repository workspace with file tree, preview and editing, chat, activity, and run-scoped changes.
- Persistent OpenHands agent execution with file tools, bounded terminal commands, task tracking, approvals, and delegated specialist agents.
- Safe preview for source, text, Markdown, JSON, CSV, TSV, images, and PDFs.
- Strict simulator-neutral `ExperimentSpec` for one-dimensional silicon structures.
- Deterministic DEVSIM compilation, packaged local execution, canonical result normalization, validation, reports, and evidence bundles.
- Deterministic Sentaurus command compilation, source mapping, signed remote protocol, and canonical result contracts for later licensed-host integration.
- Manifest-gated TCAD knowledge retrieval with source metadata, versions, review state, hashes, and citations.
- Interactive result fields, metrics, numerical samples, structure details, validation checks, and evidence downloads.
- Persistent provenance for source versions, compiler identity, simulator identity, artifact hashes, and validation results.

## Known limitations

- This is research alpha software, not a calibrated device or process prediction authority.
- Physics is limited to the capabilities declared by each backend. Unsupported requests are refused.
- The reviewed foundation supports one-dimensional silicon, constant doping, two endpoint contacts, equilibrium, and small DC sweeps.
- The DEVSIM adapter does not provide metal work functions, Fermi statistics, Auger recombination, band-gap narrowing, band profiles, mobility output, or recombination output.
- Sentaurus execution remains disabled until a separately licensed host passes the integration and conformance checklist.
- Repository commands run as the current operating-system user without VM isolation.
- Packages are unsigned and updates are manual.
- First launch can take longer on slower machines while the private backend initializes.
