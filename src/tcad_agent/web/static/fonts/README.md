# IBM Plex web fonts

These self-hosted variable WOFF2 files provide the Agent Kronig interface typography:

- IBM Plex Sans Variable, roman and italic
- IBM Plex Mono Variable, roman and italic

The files come from the official [IBM Plex releases](https://github.com/IBM/plex/releases).
They are distributed under the SIL Open Font License 1.1 in `OFL-IBM-Plex.txt`.
They are bundled locally so desktop installations remain consistent and work offline on
Linux, macOS, and Windows.
